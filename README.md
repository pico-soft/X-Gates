# X-Gates

> Ранее репозиторий назывался **XrayProxyDroid**. Старые ссылки продолжают работать через
> перенаправление GitHub, установленные версии обновляются автоматически.

Android-приложение для обхода блокировок: поднимает **локальный SOCKS/HTTP-прокси** на движке
**xray-core** и гоняет трафик через зарубежные серверы (`vless` / `vmess` / `trojan` / `shadowsocks`)
из ваших подписок. **Без VpnService** — работает как локальный прокси (модель Termux), поэтому
уживается с системным VPN, а приложения (браузер) берут прокси напрямую.

> Персональный beta-инструмент. Своих серверов не предоставляет — нужна ваша подписка (ссылки или base64).

## Зачем

- Обход блокировок (напр. в РФ) через зарубежные exit-серверы.
- Не перехватывает весь трафик устройства (это **не** VPN) → в прокси можно направить только нужные
  приложения; спокойно сосуществует с другим (в т.ч. платным) VPN.

## Как работает

- `xray-core` запускается фоновым сервисом и слушает на `127.0.0.1`:
  - **SOCKS5** — порт `10815`
  - **HTTP** — порт `10816`
- Подписка (ссылки `vless:// vmess:// trojan:// ss://` или base64-список) → разбирается в список серверов.
- Кнопка **«Самый быстрый»**: пинг всех → замер скорости живых → подключение к быстрейшему.
- Приложения на этом же телефоне настраиваются на `127.0.0.1:10815`.

## Установка

Скачайте APK со страницы [**Releases**](https://github.com/pico-soft/X-Gates/releases/latest):

- большинству телефонов — `…-arm64-v8a.apk`;
- очень старые устройства — `…-armeabi-v7a.apk`; эмулятор — `…-x86_64.apk`;
- `…-universal.apk` — если не уверены (больше по размеру).

При установке разрешите «неизвестные источники». Встроенная проверка обновлений — **Настройки → О приложении**.

## Настройка браузера (Fennec / Iceraven)

Откройте `about:config` и задайте:

```
network.proxy.type = 1
network.proxy.socks = 127.0.0.1
network.proxy.socks_port = 10815
network.proxy.socks_version = 5
network.proxy.socks_remote_dns = true
network.proxy.allow_hijacking_localhost = true
```

Эти же строки есть в приложении: **Настройки → Настройте браузер** (копируются тапом). Проверка —
откройте 2ip.ru, адрес и страна должны быть зарубежными. Выключить обход — `network.proxy.type = 0`.

## Возможности

- Мультиподписки, тест скорости, автоподключение к быстрейшему серверу.
- Автозапуск при старте и **автомониторинг** с переключением при падении туннеля.
- **Стоп-лист** (скрыть серверы по слову или точечно) и переименование серверов.
- Учёт трафика (отдельно туннель и тестовые пробники, по дням).
- **Каскадная загрузка** подписок (напрямую → через свой прокси → мимо/через системный VPN →
  через недавно рабочий сервер), когда прямой доступ к источнику заблокирован.
- Сосуществование с системным VPN.
- Проверка обновлений через GitHub со сверкой **SHA-256** и **сертификата подписи** перед установкой.

## Технически

- **Kotlin + Jetpack Compose**, `minSdk 24`.
- Ядро: **AndroidLibXrayLite** (обёртка xray-core), нативные `.so` по ABI.
- Данные (подписки / настройки / стоп-лист / трафик) — в приватном хранилище приложения (JSON).
- Релизные APK подписаны собственным ключом; сборка разбита по ABI + универсальная.
